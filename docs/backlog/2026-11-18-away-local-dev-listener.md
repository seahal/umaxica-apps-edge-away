# 開発用 Worker の待受範囲を決める

2026-11-18 調査（`a462a4f`）。対応は判断待ち。

`pnpm run cloudflare:dev` は Wrangler を `--local --ip 0.0.0.0 --port 5210`
で起動する。開発者がこのコマンドを実行している間、端末のネットワークとファイアウォールが許せば、
他端末から開発用 Worker に接続できる。E2E 用サーバーは別プロセスで、
`/__e2e/token` を提供するのはループバックに束縛されたそちらだけである。
[開発コマンド](../../package.json)・[E2E サーバー](../../e2e/server.ts)

## 判断材料

実際の端末での外部到達性と、LAN やコンテナ越しにプレビューする運用の有無は未確認。
開発者が必要とする接続元を確認し、全インターフェース待受を既定にするか、
通常はループバックに限定して外部プレビュー時だけ切り替えるかを決める。
